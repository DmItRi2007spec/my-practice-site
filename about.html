О проекте

Этот сайт создан в качестве примера статического веб-проекта для практической работы по публикации сайта на бесплатном хостинге.

Используемые технологии

  • HTML5 — разметка страниц.
  • CSS3 — оформление и адаптивная вёрстка.
  • JavaScript — обработка нажатия кнопки на главной странице.

Структура проекта

my-practice-site/
├── index.html
├── about.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── images/

Проект не использует серверную часть и базу данных. Для публикации достаточно загрузить файлы в репозиторий GitHub и включить GitHub Pages.
